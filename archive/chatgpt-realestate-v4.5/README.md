# Property Empire: Realism Edition

This folder contains an upgraded version of the original game with:

- Strongly enhanced world map rendering (terrain depth, relief, lighting, and polished ocean treatment).
- More premium map interactions (animated map pin pulses and refined UI map presentation).
- Improved investments UI to clearly support **commodities** alongside stocks and bonds.
- Updated branding/versioning for this enhanced build.

## Run
Open `index.html` in a browser.
