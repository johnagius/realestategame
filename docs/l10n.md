# Localisation scaffolding (P6.5)

Everything user-visible goes through `PE.T(key, fallback)`; **en-GB is the
source of truth** — English literals stay in the code as the fallback, only
other locales carry dictionaries. One test locale (`fr`) covers ~40 core
strings today.

## API

```js
PE.T('nav.deals', 'Deals')   // → 'Affaires' in fr, 'Deals' in en-GB, 'Deals' if the key is untranslated
PE.locale()                  // → 'en-GB' | 'fr'  (persisted in localStorage, key pe_v8_locale)
PE.setLocale('fr')           // → true; unknown locales are refused (false, current kept);
                             // fires a 'pe:locale' CustomEvent on window and re-attaches PEUI.t
PE.L10N.locales              // ['en-GB', 'fr']
PE.L10N.dict.fr              // the dictionary
PE.L10N.apply(rootEl?)       // translates every [data-t] node (document when rootEl is omitted)
PEUI.t                       // same function as PE.T, attached when PEUI exists
```

DOM convention: `data-t="<key>"` marks a node for translation; an optional
`data-t-fallback="<en-GB literal>"` keeps two-way switching exact (without it,
the node's current text is the fallback — fine for one-way). Example:

```html
<button data-t="nav.deals" data-t-fallback="Deals">Deals</button>
```

`PE.L10N.apply(document)` runs automatically on every `'pe:locale'` event
(the module installs that listener when a DOM is present), so views that only
need static re-labelling translate themselves on locale switch.

## What is wired now

- `js/engine/l10n.js` — the module (engine-side, no DOM required; loads after
  `data.js`). **Index.html change owed by the integrator:**
  `<script src="js/engine/l10n.js?v=8.1" defer></script>` after
  `js/engine/data.js`.
- `fr` dictionary over the demo key set: nav (`nav.*`), HUD (`hud.*`),
  settings (`settings.*`), common actions (`common.*`), start menu
  (`menu.*`), deal board (`deals.*`), year loop (`year.*`) — 40 keys.
- Tests in `js/sim/tests.js` (P6.5 block): fallback, locale switch + refusal,
  persistence across reloads, fr coverage, `apply()` semantics.
